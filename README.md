### 🚀 Featured Projects

#### 🏥 Clinic Appointment System
A full-stack appointment booking system with a Java Spring Boot REST API backend and React frontend, deployed to production.

**Backend Tech Stack:** Java 17, Spring Boot 4, Spring Data JPA, Spring Security, Hibernate, Flyway, PostgreSQL, Docker

**Frontend Tech Stack:** React 19, Vite, React Router, Tailwind CSS

**Features:**
- RESTful API with full CRUD for doctors, patients, and appointments
- Business rule enforcement — validates doctor availability and prevents double booking
- Database schema versioning with Flyway migrations
- Dockerized backend deployed to Render
- PostgreSQL hosted on Supabase
- React frontend with client-side routing deployed to GitHub Pages
- Package-by-feature architecture with DTOs, services, and global exception handling

**NOTE: LIVE DEMO FREE TIER BACKEND HOST HAS A SPIN UP TIME FOR THIS APP APPROX 60 SECONDS WAIT.

#### 🇺🇸 American Small Businesses Directory
A full-stack web application showcasing American family-owned businesses with secure admin management.

**Tech Stack:** React, Supabase (PostgreSQL), JavaScript, Tailwind CSS
